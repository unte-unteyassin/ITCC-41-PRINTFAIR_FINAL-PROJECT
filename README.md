# PrintFair: A Mobile-Based Printing Request and Management System for XU Library\n\nPrintFair is an Android application for XU students and library staff, supported by a separate library-PC webpage for document retrieval. It uses a shared Supabase backend for accounts, printing requests, station information, and transaction records. Station availability is updated by library staff; it is not monitored automatically. PrintFair supports the existing library process and does not replace the physical logbook or change the first-come-first-served procedure. Students bring their own paper.\n\n## Main features\n- PDF document preparation and printing requests\n- Staff-updated printing station information and PC document retrieval\n- Printing allowance validation and transaction records\n\n## Build\n```bash\nnpm install\ncordova platform add android\ncordova requirements android\ncordova build android --debug\n```\n\nThe debug APK is normally generated at `platforms/android/app/build/outputs/apk/debug/app-debug.apk`. On Windows PowerShell, use `cordova.cmd` if needed.\n\n## Supabase\nConfigure `www/backend-config.js`. Existing student and staff accounts must be provisioned by the project administrator; PrintFair does not provide public registration or password recovery. Each retrieval code is valid for 24 hours from request creation. Apply the updated `create_print_request` function from `supabase/printfair.sql` in Supabase before using the new expiry duration in cloud mode.\n\nThe kiosk page is `www/kiosk.html`. Authorized staff must sign in before retrieving cloud documents. Run `npm test` for the page-range and allowance smoke tests.\n\nCourse: ITCC 41 – Mobile Applications Development  \nInstitution: Xavier University – Ateneo de Cagayan  \nGroup Members: Gio Duldoco, Godofredo Natividad III, Yassin Unte\n
